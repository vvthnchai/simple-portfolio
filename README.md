# Simple Portfolio

A simple, clean portfolio website for showcasing engineering projects.

## Project Structure
- `index.html`: Main portfolio page.
- `style.css`: Stylesheet for the portfolio.
- `docs/`: Project documentation and specs.
- `.github/workflows/`: CI/CD configuration.

## Technologies Used
- HTML5
- CSS3

## Setup
1. Clone the repository: `git clone https://github.com/vvthnchai/simple-portfolio.git`
2. Open `index.html` in your browser.
